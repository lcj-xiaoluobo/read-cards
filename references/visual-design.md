# 书卡视觉规范

## 阅读结构

Survey 保留在 JSON、Markdown 与 HTML 导览，不进入 PNG。卡面只有 Question 提问、Read 精读、Recite 复述、Review 复习的完整英文与中文，以及对应小图标；不加独立 S/Q/R、阶段编号或 SQ3R 角标。英文原文需核对，译文保留但不加“中文转译”标签。答案、边界、验证依据放在卡外；不提供自评 UI，Review 默认留白。

## 默认外观

用户最新参考图拆解见 [reference-style.md](reference-style.md)。默认采用柔和渐变外底、白色圆角主面板、紫色分类和深色大标题。保留初版四区左右分栏；不恢复历史杂志式两行大标题方案。旧版奶油点阵和黄色标题底纹仅留在备份；新默认取消它们，使白面板和标题更干净。用户另有样式要求时优先。

- 分享 PNG 为 1080×1440，RGB。外底由左上 #cfdffd、右上 #ffebca、左下 #c7b8e5、右下 #f2c6d2 平滑过渡，白色面板位于 (48,42)–(1032,1402)，圆角约 36 px，单层低透明度软阴影。
- 标签紫 #8562ce；标题 #292820，说明灰 #827b70。四区底色与左边线：提问 #e7eff6 / #527e9e，精读 #e7f1e9 / #56866c，复述 #faf0e1 / #b68244，复习 #f7eaf0 / #ab738c；各区横向渐淡到 #f5f8fc、#f4f9f5、#fdf8ef、#fcf5f8。
- 四区 x=76，宽 928；依次 y/h=344/184、550/384、956/206、1184/132。正文起点 282，宽 688。标签、图标位于左栏，正文在右栏。图标约 32 px，统一圆润线条和区块强调色，先图标、再英文、再中文，垂直居中。
- 中文标题苹方 SC Semibold 76 px，定义 Regular 31 px，中文正文 Regular 35 px，英文引文 Georgia Regular 34 px，译文中文 31 px，出处 22 px。完整英文标签 28 px、中文 27 px。仅使用本地字体；缺失时找本地中文无衬线/英文衬线替代并检查字形。默认苹方集合索引 3/11，可用 CLI 指定。
- 左下角作者头像或内容图标位于 (78,1330)，64×64 圆形；相邻页脚 20 px，不侵占 Review。头像优先，缺合适素材用 growth/book/compass 图标；presentation.icon=none 可关闭图标。作者照片与图标不同时展示。
- 标题是一行；英文按单词换行，中文避免孤立闭合标点和过短尾行。标题、原文或正文过长时精简冗余或拆分学习目标，不裁切或缩到难读。

## 数据与导出

可选作者与图标的数据写法见 [card-format.md](card-format.md)。头像文件相对 data.json 定位；网页把图片嵌入为 data URI，因此 HTML 可离线分享。JSON 保留文件路径和来源，复习导出不混入大图二进制；迁移数据时一并带头像文件。

render_poster.py 与 HTML 使用同一数据、色标和图标语义。四角颜色和背景由 scripts/visual_assets.py 统一：HTML 内嵌二维渐变 SVG，PNG 按同一四角颜色完整插值。PNG 是 Pillow 排版，不是网页截图，换行可能不同；.layout.json 记录实际尺寸、文字边界、字体、区块颜色、阶段图标和页脚素材类型。超过文字区域就报错，不静默裁切。

检查实际 PNG：尺寸正确，四区顺序与图标可辨，中英分字体，原文和无标签译文完整，Review 留白，作者身份与图片来源清楚或内容图标贴合，页脚与复习区不重叠。检查 HTML 的搜索、筛选、展开、备注导出；浏览器受限时如实报告交互检查缺口，不绕过限制。


## 长内容与纯净预览

HTML 在字体就绪后检查页头、正文区和页脚；内容超出固定比例时展开卡片高度，提示“内容较长，已展开显示全文”。正常长度仍采用 3:4，展开后的网页用于完整阅读。纯净预览不将滚动区改为 hidden；打印前同样完成字体与布局检查。PNG 继续严格按 1080×1440 检查内容，超长时报告具体区域，不以网页展开代替分享图验收。

网页展开逻辑需在允许的浏览器环境中检查。仅静态脚本检查或模拟尺寸不等于浏览器现场验收；交付说明区分已验证的 PNG 与尚未现场验证的交互。
