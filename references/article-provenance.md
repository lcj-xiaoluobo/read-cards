## 文章的核心目标

读书要形成使用闭环。作者以《纳瓦尔宝典》为例，描述用 WorkBuddy 的拆书 Skill 把书转成 50 张认知卡，支持写作检索、日常复盘与定期知识归类。耗时是作者的案例陈述，未实测复现。

## SQ3R 与五步制作

SQ3R 为 Survey 概览、Question 提问、Read 精读、Recite 复述、Review 复习。文章建议先梳理自己的读书方法，有自有方法可用其框架替代。

| 制作步骤 | 提取的方法与产物 |
| --- | --- |
| 整书 Survey | 核心问题、3 条有力主张、5–8 个主题关键词、3 类读者场景，附章节；片段只作片段概览 |
| 五模块提取 | 框架、原则、案例、反例、术语；内容加章节；每模块约 40 条是作者给的可调规模 |
| 三项筛选 | 跨场景、回答新问题、超越常识；三项通过入选，一至两项备用，其他淘汰并说明理由 |
| 逻辑分析与验证 | 主题分类、合并建议、3 个原文没直接回答的问题与调用卡片的推理 |
| SQ3R 知识卡 | 整书建议 30–60 张、片段 5–15 张；卡名、定义、短引文及出处、重构、触发场景、至少两条边界、验证等级；示例按六模块组织 |

## 卡片交付与视觉规则

三份产物内容一致：按模块分组的 Markdown、支持筛选搜索与单卡弹窗的 HTML、作为后续渲染与可选同步唯一真实来源的 CSV/JSON。

单卡比例 3:4；标题霞鹜文楷、其他系统字体。四条色带分别是 Q 提问蓝、R 原文绿、Recite 复述橙、Review 复习粉；卡面不显示数字编号。右侧正文按中文句末标点与分号换行，行高 1.75。Review 初始留白供以后填写，边界仍保存到数据。点击任意卡片弹出 3:4 单卡。作者示例文件名包含 50，本技能改用实际数量。

## 使用闭环

写作时关键词检索；日常抽卡关联自己的行为；定期把关联内容分类。文章提到未来与阅读平台、微信读书技能联动，但没有提供同步接口或完整实现，不据此创建未经验证的依赖。

## 本技能的适配与补充

- “超越常识”视为信息增量，不等于真实性；真实性靠原文及研究证据。跨场景和回答新问题是迁移自检，不是实证验证。
- 面向文献时保留专业定义、研究设计和关键发现，即使它们不适用于两个无关场景；增加数据、不确定性、研究局限与因果边界规则。
- 字体优先用本地已安装霞鹜文楷，缺失时回退，保持离线可用。
- 六主题按材料选择；没有原文反例时不编造；数量按知识密度，避免硬凑 50。
- 引文默认短且需核对，遵守实际环境的累计引用限制；未核对逐字内容时显式用转述。
- 将边界保存并置于辅助详情，维持 Review 留白；新增可填写复习备注与 JSON 导出，明确不会自动写磁盘。
- v2.1 起 CSV 作为可选派生产物（`--csv`），满足原文的 CSV/JSON 要求；JSON 仍是唯一内容源，CSV 不反向修改。新增本地原文提取脚本，EPUB/DOCX/PDF 不再依赖用户手工粘贴。
- `analysis.md` 保留概览、候选、筛选理由、合并和迁移自检；Markdown 与 HTML 从 JSON 生成，保证一致。

正文关于“带问题阅读吸收率提高三倍”等描述没有附可核验研究；不将其写成技能中的科学事实或效果承诺。
