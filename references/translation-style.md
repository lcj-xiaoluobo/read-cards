# 中文文案：精要、诗意、有文韵

借鉴 translate-book 的自然流畅、简洁表达与术语一致原则，将其用于单卡短引文，并按标题、译文、提问和复述的不同用途选择文风。文采来自准确的动词、顺畅的节奏和克制的语言。

- 先保义：确认主语、对象、条件、程度、否定及因果关系。原文的“更可能/更多”不能变成“一定/唯一”；热爱不能自动推出成功。
- 后炼句：删掉翻译腔和空泛修饰，少用层叠的“的”。可调整中文语序、长短句与停顿，可在标题采用四字对句、五言或七言的节奏，正文随义成句，不为了齐整删除必要信息。
- 术语按当前材料统一：从实际定义、学科和版次建立简短术语表，优先采用用户指定译名。不同书、学科或作者可能给同一词不同含义，不把示例书的译名自动套到其他材料；长材料可将术语表记入 analysis.md。
- 文学性适度：允许“循着”“寻得”等自然用词，不加入原文不存在的命运、灵魂、必然成功或夸张比喻。
- 分清字段：original 按 original_language 保存实际来源语言的短引文或明确标注的转述，original_kind 区分二者；original_translation 是忠实自译；reconstruction 是结合上下文的独立复述。中文原著不编造英文，转述不加逐字引号。
- 以原句回读：压缩后仍能对应每个必要语义，读者不必猜省略的逻辑；若精要与准确冲突，优先准确。

Read 中英文在上、中文在下，不写“中文转译”前缀；HTML 卡外来源说明仍注明中文为本次自译，非出版译本引文。Survey、答案、边界及自评不移上卡。

## 《纳瓦尔宝典》示例（不跨书套用）

当前示例依该书语境将 specific knowledge 译为“专长”；genuine curiosity 保留真实、自发的含义。示例译文：“循着天赋、真切的好奇与热爱，专长更易寻得。”这是忠实而凝练的自译选择，不是所有材料的通用句式；也不把它解读为经过验证的成功概率。若改译文，重新回查原句与上下文，不能仅为押韵改动寻找途径或程度。

## 标题文韵与自然正文

- 标题优先 5–12 字，尝试四字对句或五言、七言式原创句；保留至少一个能识别知识点的概念，不能只剩“花开自有时”等空泛意象。
- 标题可压缩、对举，例：“循趣深耕，磨砺专长”。这是原创主题提炼，不标成古诗名句或作者原话。未经原文核对不能给诗句安上古人姓名。
- 定义可有文韵；提问与复述采用原书自然、直白的语言，保留对象、做法与必要条件，不用“欲择”“何以”“不唯”等仿古表达。参考答案也用清晰的自然语言。
- 标题、定义可用“循、择、磨砺、深耕、寻得”等易懂词形成文韵；提问与复述不强求这些用词。避免难解典故、刻意仿古句法和网络鸡汤。
- 提问像读者真实会问的问题；复述像用自己的话讲清楚作者的意思，不写成格言。复述按完整句分行，避免术语拆行。事实说明、来源、限制与专业术语保留清晰准确的表达，不以文学性遮掩语义。
- 示例定义：“天赋为根，好奇为径，热爱为源。”示例问题：“我该怎样找到值得长期投入的专长？”示例复述：“找到你有天赋、真正好奇并热爱的事。继续钻研，在实践中磨练自己的专长。别只因为某个职业热门就去学。”


## 交付前的文案核对

逐卡检查：标题能识别知识点；问题能自然提出且答案直接响应；引文语言和引用/转述身份正确；译文保留条件、比较对象与程度；复述是完整自然句；作者主张、证据与模型练习可区分。中文原著按实际语言展示，英文新卡原则上生成中文译文；用户明确要求只保留英文时按其要求执行。旧英文卡缺译文时审计给出 missing-translation 提示，允许读取旧数据，但不能把缺译文的卡片称为已完成双语版本。
