# 参考图风格拆解与应用

## 观察结论

这是一张清爽的科技知识海报，嵌在手机视频界面里。分析对象是中间海报；黑色导航、时间、字幕、互动数字和进度条属于平台界面，不进入书卡。

| 维度 | 图中特点 | 书卡的应用 |
| --- | --- | --- |
| 布局 | 多色渐变外底包围白色圆角大面板；信息左对齐，上方标题、中部模块、下方人物，留白充足。 | 渐变外底与白色主面板；标题在上，四个阅读区仍是左标签右正文，页脚保留小头像或图标。 |
| 层级 | 小栏目名、灰色引导句、超大紫色数字与黑色粗标题、灰色说明，大小与颜色共同建立层级。 | 以知识标题为第一焦点，定义次之；紫色分类与卡号辅助定位。只有原文确有且需要突出数字时才强调数字。 |
| 图形 | 六个白色功能块呈三列两行；彩色圆形图标辅助快速识别。它是功能分类网格，不是统计图表。 | 依 SQ3R 阅读顺序安排四区，不硬套六宫格；阶段用小线性图标。材料确需比较或关系图时，依据真实内容另行设计。 |
| 字体 | 可观察到现代无衬线中文字形：标题粗重、说明较轻；英文栏目大写并加字距。仅凭截图不能确定字体名称。 | 中文用本地苹方 SC，标题 Semibold、正文 Regular；英语引文和阶段名用 Georgia 正体。网页栏目可用系统无衬线。 |
| 色彩 | 左上浅蓝、右上奶油黄，底部转淡紫与玫瑰粉；白面板与深色文字保证可读性，亮紫、蓝、珊瑚红是少量点缀。 | 外底浅蓝→奶油→淡紫/玫粉；紫色分类；四区继续蓝、绿、橙、粉的柔和渐变；正文不做渐变。 |

## 借鉴范围

保留白面板、渐变外底、强弱清楚的字号层级、小图标与左下人物位置。卡片沿用已确认的文风和四区分栏，不抄参考图的品牌、标题、数字、人物或平台按钮。标题可有古诗文韵；问题和复述自然清楚；精读有英文与中文译文，译文无标签；复习留白。

图标不是装饰填空：提问用问号气泡，精读用书页，复述用对话气泡，复习用回环箭头；概览在网页用地图图标。页脚的萌芽、书页、指南针分别对应成长、阅读、方向。若这些不贴合材料，可选 none，并为新类型扩展有语义的图标。

作者照片只能使用身份明确、来源有据的图片。不要截取参考图人物当作书中作者，也不要用生成脸冒充真人。区分作者、编者、研究者和书中人物，例如纳瓦尔与《纳瓦尔宝典》编者的角色不同；数据 role 须写实际身份。图片来源与署名在 HTML 卡外说明，页脚只放姓名和简短角色。
