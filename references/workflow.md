# 五步拆解与长材料处理

## 1. 概览

核对题名、作者、版本/年份及实际材料类型。用一句话描述问题，提炼主要主张与主题，指出读者场景；数量随材料调整。把目录作为结构地图，不能把目录当成读过正文的证据。

长材料在 data.json 的 coverage_map 中按章节/小节记录来源 ID、位置、状态及卡片 ID；部分读取的章节标 partial 并在 note 写已读段落。对同一材料继续拆解时先读既有数据和 analysis.md，从未读或部分读取处继续，不重做已核对内容。

## 2. 提取

以框架、原则、案例、反例、术语五种视角收集候选，记录条目 ID、要点和位置。短文可合并过程记录；长书逐章理解后再跨章整合。没有案例/反例就写未提供，不能补造。

章节“read”表示实际读取，不表示每节都必须出卡。读过但未入选的重要章节仍说明为何不成卡；研究局限即使不新奇也要保留。

## 3. 筛选

先检查用户相关性、来源可追溯性、核心性和信息增量，再判断跨情境与生成性。对行动方法可试举两个不同情境，但不强行将专业结论外推。记录入选、备用、合并、淘汰及理由；关键专业内容可标专业保留。候选数量或三项筛选不能代替证据支持。

## 4. 整合与应用检验

按实际主题分组；合并同义表达但保留互补条件，不合并互相冲突的主张。关系可标“前置/对比/补充”并用稳定 ID 关联。

提出若干材料未直接回答的真实问题，给出调用卡片、条件和推导；约三个足够，短材料可少。没有支撑就报告缺口。记录这只是应用自检，不能把生成的例子或答案标为原书案例。

## 5. 写卡与覆盖复核

一张卡一个学习目标，避免金句列表。新数据按照 v3 字段明确问答、原文/重构、引用支持与来源范围。对章节地图逐项核对：是否跳章、是否漏掉关键反例、是否因视觉长度删除必要条件。

整书的高价值抽样可以完成，但 coverage 必须称“全书已读后的精选卡片”，不能宣称穷尽全部知识；未读完称“已读范围的卡片”。卡片数量不足时先减少重复，不改造范围声明。

## analysis.md 的适当内容

只写足以回查和继续工作的记录：材料身份和范围、主题地图、章节状态、候选简表、筛选/合并理由、应用自检、尚缺内容。不要输出大量重复卡片正文或隐藏思维过程；理由用简明的可验证依据即可。
